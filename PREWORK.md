# Before Part 1

1. Sign in to local Codex or Claude Code.
2. Clone the repository, or unzip the downloaded package.
3. Open that folder as the local project.
4. Have your company website and two target-company domains ready.
5. Know who you sell to and what you can offer them. The agent can help if those answers are missing.

Use macOS or Linux. On Windows, use Codex or Claude Code inside an installed WSL environment. Native Windows has not been verified.

Open START-HERE.html. Copy one complete prompt. Your first result is company-motion/COMPANY.md.

No API keys, sender setup or paid data tool are needed for Part 1. A missing Python interpreter is handled by the startup check with the official installer. No Homebrew is needed.

Keep the company brief, pages, saved skill and PROGRESS.md. Use this same project at the next workshop.

Before Part 2, confirm whether your company permits you to authorize your own mailbox. Ask your Workspace administrator early if app sign-in is restricted. The next workshop supplies the detailed connection guide and exercises.
