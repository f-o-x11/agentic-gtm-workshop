# Before each workshop

## Part 1: pages and a reusable skill

Have Codex or Claude Code signed in and able to open a local folder and public websites. Clone the repository or unpack the participant ZIP. Open the whole workshop folder as your local project.

Bring your website, one buyer segment, the offer you can actually make and two target-company domains. A rough answer is enough to start. The agent helps turn it into a sourced company brief.

Use START-HERE.html. The agent checks Python and saves the working interpreter. If the launcher cannot find any supported interpreter, use the official installer it links. A default Python 3.9 can still launch a newer saved interpreter. No paid API is needed for Part 1.

If `python3` is not found, the agent first finds an installed Python 3.10 or newer and uses its exact path. If none exists, install Python from https://www.python.org/downloads/ and retry. No Homebrew is needed. A missing interpreter receipt triggers a new search. An unusable saved interpreter requires `bootstrap --reset-python`.

## Part 2: an email pilot

Start this setup as soon as you receive the package. Company administrator approval can take days. Send future cohorts these instructions at least two weeks before class when dates allow.

| Need | Ready when | If blocked |
|---|---|---|
| Your own Gmail account | Account read returns your exact sender. | Ask your Workspace administrator about the named OAuth app. Keep sends paused. |
| Google Cloud desktop OAuth | Gmail and Calendar APIs enabled, client downloaded, browser consent completed. | Follow SETUP-SEQUENCE.md. A client file alone is not a connection. |
| Current exclusions | Customers, open deals, opt-outs and relationships have complete current coverage. | Prepare messages locally. Do not claim an empty list is complete. |
| Work-email validation | ZeroBounce balance and exact valid receipts are available, or a supported fresh validation receipt. Employer and validation evidence must still be within seven days at release; recheck stale receipts. | Review copy and keep held addresses paused. |
| Current person evidence | Source shows the actual current employer and role. | Use one finder only if official sources are insufficient. |

The self-test uses your own sender. The ten prospect messages remain locked until the exact self-test matches Gmail Sent and you approve the exact prospect keys. Partial results stay partial.

## Part 3: operate the workflow

Bring the same project and its actual outcomes from Part 2. You will read replies and bookings, inspect prior attempts, prepare the next bounded cycle and save the operating instructions. No new paid channel is required for this main lane.

These extensions are optional:

|---|---|

| Gifting | Owned Loop & Tie team, API access, funded collection and actual scheduler binding. |

| Calendar bookings | Owned Calendly account or supported calendar source. |

Entering a key does not finish setup or approve spending. See API-CONNECTIONS.md for the exact input, supported result and native check. You can watch the optional demonstration and connect that channel later.

## Computer compatibility

The launcher and fresh-copy checks were run on macOS, including system Python 3.9.6. Windows execution has not been tested. Do not count an untested Windows setup as working; use the first blocked check to identify its actual missing app, interpreter or file permission.
