Source and portable workshop adapters reviewed October 5, 2026. This is a code review. No production provider action ran during preparation.

## Gaps that remain visible

1. No postal direct-mail provider exists in these files. Loop & Tie delivers a gift invitation by email.
2. The Calendly adapter reads events. It does not create or book appointments.
3. HubSpot meeting rows do not establish attendance. The exact contact, email and meeting-start join is not implemented.
4. A hosted HTML hash does not prove desktop/mobile layout or a successful form conversion. Test both in the actual browser and destination.
5. The minimal portable config enables Gmail history. Optional settings.history_sources can add actual Instantly and Gojiberry sources. Native mode needs complete relied-on history.
6. Social provisioning prepares inert contacts in an existing owned list. It does not create a list, connect a LinkedIn seat or activate a whole campaign. Those need actual native owner setup.
7. The source research transport saves response bodies but does not retain all provider cache/source-age headers. A new local receipt time alone must not establish current employment.
8. Unattended operation needs strict native mode with actual maintained customer, CRM, full-history and booking sources. Snapshot mode still needs a complete owner export from the past 65 minutes. Scheduling alone supplies neither coverage.
9. A current native delivery result remains an attendee test. Code and council review cannot prove that another person's account works.

## How the workshop uses the gaps

Part 1 produces useful company assets without a paid provider. Part 2 builds one complete Gmail path. Part 3 uses the same company context and checks for gifts, LinkedIn, pages and creative. Each unavailable provider still leaves a concrete reviewed artifact, with its missing live setup named.

The workshop must not count a prepared message as sent, a created gift as redeemed, a generated ad as launched, or a booked meeting as attended.

The public Metadata connector exposes audience and campaign tools. Their public declarations are preserved in `METADATA-PUBLIC-TOOL-SCHEMAS.json` for implementation reference. They were inspected without calling the production tools. The portable runtime calls a bounded set of those tools for creative, audience, draft, read and pause operations. Launch/restart remain held pending verified budget/readiness contracts. Local tests establish request and hold behavior. They do not prove a running native campaign or grant a launch budget.

The final gift gate requires a truthful, fresh authenticated provider UI capture, both real input names inside the same numeric form, actual provider URL and capture time, configured team match, and an authenticated native scheduler receipt. Capture evidence older than 65 minutes holds import and sending. The code cannot authenticate fabricated HTML. Read the actual owned tab.

Campaign draft channel fields support LinkedIn and Facebook only. Unknown creative, advertising and contact-preparation requests use the original receipt and owned provider read/UI route in PROVIDER-RECOVERY.md. Generic reconcile is not a catch-all for these requests.
