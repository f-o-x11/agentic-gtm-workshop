# API status matrix

Source code reviewed October 6, 2026. Live attendee connections have not been run by this guide.

| Tool | What entering it enables | Required when | Local support | Key alone is insufficient because |
|---|---|---|---|---|
| Google: Gmail, Calendar and optional Sheets | Send from your own approved mailbox, read the exact Sent message, read replies and exclude existing calendar meetings. Optional Sheets access reads your customer list. | Required for the live email path | Supported in portable package | A Google API key does not unlock private email. A downloaded OAuth client file alone is not a signed-in mailbox. This code reads calendars; it does not create appointments. |
| Your current customer, deal and opt-out list | Remove customers, open deals, opt-outs and existing relationships. Snapshot mode uses a current owner-reviewed export. Native mode reads actual maintained customer, CRM, history and booking sources each cycle. | Required before any live outreach | Current snapshot supported; strict complete-native mode supported for repeated operation | A blank export, partial range, stale source or unknown customer status cannot establish company-wide coverage. Native mode needs complete positive current receipts and does not fall back to a snapshot when its sources fail. |
| ZeroBounce | Check the exact work email. Store its returned status and actual checked time. | Required for fresh validation on the email path | Balance reads, exact-address validation and stale-complete renewal supported | Validation does not prove current employment, permission to send, absence of a deal, or delivery. |
| Sixtyfour | Find companies or people with bounded filters. Find a professional email for a sourced person. | Optional research choice | Search and professional email discovery supported | The local adapter does not expose Sixtyfour's full intelligence, phone, monitor or workflow APIs. Its email lookup has verify_emails:false, so separate validation is required. |
| Exa | Find current web sources for a company, product or buying signal. Read linked official sources to support the message. | Optional official-source research | Search supported in portable package; original source had credential plumbing only | Search snippets do not verify employment or email delivery. Exa does not send outreach. |
| Apify | Read public LinkedIn person/company data and recent public comments using the selected actor. Save the accepted run ID and read its dataset. | Optional profile and public-signal source | Five allowlisted actors supported | A scraped comment is not buying intent or authorization. This adapter does not post, invite or message on LinkedIn. |
| Triguna | Read a person profile or company record from an exact existing native identifier. | Optional identity lookup | Person and company lookup supported | There is no people-search method in this adapter. You need the LinkedIn URL or identifier first. |
| MoltSets | Search people, look up a business email from LinkedIn, or look up a mobile number. | Optional people and work-email source | Three tools supported | The workshop needs no mobile number. The adapter exposes only search_people, linkedin_to_business_email and linkedin_to_mobile_phone. A risk score is not the package's fresh valid email verdict. |
| RocketReach | Look up a known LinkedIn profile and read the status of that same native person handle. | Optional contact lookup | Exact profile lookup and same-handle status check supported | The adapter does not expose a full search workflow. It does not send mail or validate your sender. |
| Instantly | Read past Instantly emails to avoid duplicate outreach. Use an available Instantly-funded finder from its actual provider registry. | Optional existing-history and email-finder source | Selected enrichment and optional complete history reads supported | This adapter does not send through Instantly. A key does not make the portable setup read its history or make an unavailable finder usable. Select only a live funded provider from its registry. |
| Calendly | Read exact bookings and cancellations for your selected event types. Exclude booked people and accounts from cold outreach. | Optional when your company uses it | Booking and cancellation reads supported | The adapter does not create a Calendly event, choose a time, send a scheduling link, or verify attendance. Reading a booking does not establish that a meeting happened. |
| HubSpot | Read open deals and associated company domains. Read existing demo-form submissions. Record native meeting outcome rows. | Optional when your company uses it | Open deals, demo-form submissions and raw meeting-outcome reads supported | The adapter does not create/update CRM deals or submit forms. Meeting attendance stays unknown because the exact meeting/contact association join is missing. |
| Salesforce | Read open opportunities and their exact account websites. Exclude those company domains. | Optional when your company uses it | OAuth and open-opportunity reads supported after portable owner config | The adapter does not write opportunities or infer pipeline revenue. A CRM connection alone does not prove the engine caused a deal. |
| Your current customer Sheet or revenue Sheet | Read the complete customer Sheet and exclude exact current-customer domains. The original revenue schema also reads positive recognized revenue relationships without proving current-customer status. | Optional native customer source | Customer-domain status format and original revenue schema supported | A Sheets key alone cannot maintain customer status. Use actual maintained statuses, not guessed revenue. The source revenue layout is specific. A generic CSV or partial range is not automatically a complete customer source. |
| Loop & Tie | Create one exact email-delivered gift and read its native creation/sent state. Require a verified meeting scheduler gate. | Required for the gift extension | Meeting-gated email gift creation and native readback supported | A token alone cannot fund a gift, set its meeting gate, provide a native numeric scheduler binding, or prove redemption. This adapter does not send postal mail. |
| Gojiberry | Prepare inert contacts in an existing owned list. Release only an exact approved contact and read native queued/sent state. Send an individually approved existing-thread message when its native prerequisites pass. | Required for the LinkedIn extension | Paused contact preparation and exact contact/message release supported; campaign activation stays in owned UI | A key does not connect a LinkedIn seat, create a list or activate a whole campaign. The runtime holds campaign activation because it could release unrelated contacts. Queue state does not prove delivery or acceptance. |
| Metadata | Read the owned Metadata account, integrations and campaign status. Generate brand kit and creative. The portable extension can prepare audiences, offers, budgets and campaign drafts, plus exact native pause with separate advertising authority. | Optional creative and advertising extension | Creative, audience/draft/read/pause supported; launch/restart currently held | A token does not connect your ad accounts, fund spending or prove a running campaign. Launch and restart are held until existing campaign budget and native readiness contracts are verified. The original v5 source had creative only. |
| Local landing page and existing form | Create a local HTML page with the agent. Verify bytes from a recorded owned hosted URL and inspect an existing HubSpot form contract. | Optional publishing extension | Local page build and existing hosted/form reads supported | Local HTML is not a public deployment. A hosted content hash is not browser or form acceptance. Netlify publishing has its own supported entry below; Vercel and AWS publishing are not wired here. |
| Netlify: publish one HTML page | Publish one reviewed HTML file to your owned workshop site and verify the returned deployment and exact HTTPS bytes. | Required only for runtime page publishing | Supported portable extension; original source had no upload | This uploads index.html for the whole selected site. Use a fresh workshop site. It does not add image files, submit your form, manage DNS or verify desktop/mobile usability. |
| Tavily: optional research alternative, not wired | Nothing inside this runtime. A separate explicitly connected coding-agent tool could use Tavily to find public sources. | Not required by this package | No local adapter or CLI operation | Entering a Tavily key in this runtime will not activate research. There is no V5_TAVILY environment or config contract. Do not claim search, enrichment or email validation from a saved key. |
