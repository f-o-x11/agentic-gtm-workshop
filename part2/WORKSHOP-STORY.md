# The Part 2 story

Part 1 gave participants company facts, pages and a reusable skill. Part 2 connects that work to one small outbound email pilot.

1. Show a real Metadata email and its actual Gmail Sent record. Explain the operating tree before the tools.
2. Reopen the existing project. Verify the actual sender and stop rules.
3. Select ten real companies, check one buyer per company and write sourced messages.
4. Review the exact eleven-message scope. Send one owned test and inspect the actual Sent message.
5. Release only the approved eligible pilot, read each result and save the email skill.

Use extra time to read real replies/bookings and prepare a next-run prompt. The program does not send automatic replies or follow-up emails. Scheduling waits for two correct manual cycles and current native source connections.

Explain one choice in each prompt, show one result, then stop talking while the participant works. A preview, a stored key or a provider acceptance never becomes a claimed live outcome.
